# Software Construction

This repository contains laboratory assignments for the **"Software Construction"** course.  
Each lab assignment is developed in a separate branch (`laba1`, `laba2`, …).  
The main branch contains only documentation and a description of the project structure.


## Technologies Used

- Programming language: **C#**
- Development environment: **Visual Studio**
- Project type: mainly console applications (other types may be added later)


## Repository Structure

- **main** — the current branch with documentation (`README.md`).
- **laba1** — the first lab assignment (console project in C#).
- **laba2** and onwards — subsequent lab assignments.


## Repository Rules

**1.** Each lab assignment must be developed in a separate branch named `laba{N}`, where `N` is the lab number.  
**2.** The main branch stores only documentation and general descriptions.  
**3.** All projects are created in Visual Studio and pushed to their corresponding branches.  
**4.** The commit history should reflect the progress of the work.
